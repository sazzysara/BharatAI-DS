# Data Science & ML Notebooks

Jupyter notebooks for the Bharat AI Hardware Intelligence Platform:
- `01_eda.ipynb`: Exploratory data analysis, missing-value treatment, distributions, correlation heatmaps, arithmetic intensity & TOPS/Watt feature engineering.
- `02_model_training.ipynb`: Machine learning models (Linear Regression, Random Forest, XGBoost/LightGBM) trained to predict latency and power with K-Fold cross validation and SHAP explainability.
