# Hardware & Benchmarks Dataset Directory

This directory contains verified datasets for the Bharat AI Hardware Intelligence Platform:
- `hardware_devices.csv`: 40+ hardware accelerators (NVIDIA Jetson, Intel NPU, Coral, Raspberry Pi, Vicharak, Mindgrove, C-DAC) with verified datasheet metrics.
- `benchmarks.csv`: Public inference benchmark results (MLPerf, vendor whitepapers).
